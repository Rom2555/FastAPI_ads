# Advertisements API

API для работы с объявлениями, построенная на FastAPI и PostgreSQL. Реализована полноценная система аутентификации (JWT) и разграничения прав доступа.

## Особенности

- CRUD операции для объявлений и пользователей
- Поиск объявлений по заголовку, автору и цене
- Аутентификация и авторизация с использованием JWT (срок действия токена — 48 часов)
- Разграничение прав доступа (гость, пользователь, администратор)
- Автоматическое создание учетной записи администратора при первом старте
- Безопасное хранение паролей (хеширование bcrypt)
- Валидация данных с Pydantic
- Автоматическая документация API (Swagger UI, ReDoc)
- Контейнеризация с Docker и Docker Compose

## Требования

- Docker и Docker Compose (для запуска в контейнерах)

## Запуск с Docker

1. Склонируйте репозиторий:
   git clone <URL репозитория>
   cd FastAPI_ads

2. Скопируйте пример файла окружения и настройте его:
   cp .env_example .env.

3. Отредактируйте .env, указав свои данные для PostgreSQL, секретный ключ для JWT и данные для первого администратора.

4. Запустите приложение:
   docker-compose up --build

5. API будет доступно по адресу: http://localhost:8080


## Документация API

После запуска приложения откройте:

- Swagger UI: http://localhost:8080/docs
- ReDoc: http://localhost:8080/redoc

## Как авторизоваться в Swagger UI:

1. Нажмите кнопку Authorize (замочек) в правом верхнем углу.
2. Введите username и password (для начала можно использовать данные администратора из .env).
3. Нажмите Authorize. Теперь все закрытые эндпоинты будут работать от вашего имени.

## Права доступа

Система использует три уровня доступа:

## Неавторизованный пользователь (гость)
- Создание аккаунта POST /user
- Авторизация POST /login
- Получение пользователя по ID GET /user/{user_id}
- Получение объявления по ID GET /advertisement/{advertisement_id}
- Поиск объявлений GET /advertisement

## Авторизованный пользователь (роль user)

- Все права гостя
- Обновление своих данных PATCH /user/{user_id}
- Удаление своего аккаунта DELETE /user/{user_id}
- Создание объявления POST /advertisement
- Обновление своих объявлений PATCH /advertisement/{advertisement_id}
- Удаление своих объявлений DELETE /advertisement/{advertisement_id}

## Администратор (роль admin)

- Любые действия с любыми сущностями (полный доступ). 
Если пользователь пытается выполнить действие, на которое у него нет прав, сервер возвращает ошибку 403.

## Структура проекта

- `app/` - основной код приложения
  - `app.py` - точка входа и настройка FastAPI
  - `models.py` - SQLAlchemy модели
  - `schemas.py` - Pydantic схемы
  - `database.py` - настройка базы данных
  - `dependencies.py` - зависимости для эндпоинтов
  - `auth.py` - логика авторизации
- `requirements.txt` - зависимости Python
- `Dockerfile` - образ для приложения
- `docker-compose.yml` - конфигурация для Docker Compose
- `.env_example` - пример файла окружения
